## Studio workflow

### Signup
Email + password -> choose Studio -> onboarding -> complete -> profile.

### Discover
Normal filters or AI requirement search.

### Requirement
Create event/work card -> open -> request freelancers.

### Request
Pending -> Freelancer accepts/rejects -> Studio confirms one -> confirmation.

### Privacy
Before confirmation: no private event-person contact information.
After confirmation: reveal private event-person information.

## Freelancer workflow

### Signup
Email + password -> choose Freelancer -> onboarding -> complete -> profile.

### Profile
Edit professional details, skills, services, equipment, charges.

### Portfolio
One portfolio with categories and images.

### Availability
Maintain rolling 10-day availability.

### Request
Receive request -> view limited details -> message -> accept/reject.

### Completion
Confirmed work -> in progress -> completed -> rate Studio.

## Admin workflow

Login -> dashboard -> monitoring pages. No general mutation actions.

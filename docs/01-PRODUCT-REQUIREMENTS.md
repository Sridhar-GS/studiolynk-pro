# Product Requirements

## Users

### Studio
Needs to find and collaborate with freelancers for photography/video work.

### Freelancer
Needs to present professional information, portfolio, equipment, pricing, availability, and receive work requests.

### Admin
Needs monitoring visibility for the academic prototype.

## Primary journeys

### Studio journey
Signup -> Role selection -> Studio onboarding -> Profile -> Discover freelancers -> Filter/search or create requirement -> AI matching -> Freelancer profile -> Send request -> Message/negotiation -> Freelancer accepts -> Studio confirms -> Private details revealed -> Work -> Complete -> Rating.

### Freelancer journey
Signup -> Role selection -> Freelancer onboarding -> Profile -> Portfolio -> Availability -> Receive request -> View limited work information -> Message -> Accept/reject -> Studio confirms -> Work -> Complete -> Rate Studio.

## Product principles
- Simple.
- Role-specific.
- Availability-aware.
- Portfolio-centered.
- AI-assisted, not AI-dependent.
- Understandable for academic review.

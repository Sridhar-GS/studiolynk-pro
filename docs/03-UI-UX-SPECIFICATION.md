# UI/UX Specification

## Visual direction
Professional photography-oriented interface. Clean cards, strong imagery, restrained visual decoration, clear hierarchy.

## Components
Use reusable:
- Buttons
- Inputs
- Selects
- Date/time pickers
- Cards
- Dialogs
- Toasts
- Tabs
- Badges
- Avatar
- Image gallery
- Empty states
- Skeleton/loading states

## Icon rule
Use Lucide React. Do not use emoji when a suitable interface icon exists.

## Forms
Every field:
- Label
- Icon where appropriate
- Placeholder
- Validation
- Error message
- Loading state
- Disabled state where appropriate

## Visual selection
Services, skills, equipment and categories may use visual cards with icon/image.

## Responsive navigation
Desktop: top navigation.
Mobile: bottom navigation.

## Freelancer profile
Profile should be the first impression:
- Large profile image
- Name
- Location
- Experience
- Rating
- Bio
- Skills
- Services
- Equipment
- Pricing
- Availability
- Portfolio gallery
- Request action

## Portfolio
Instagram-style category grid with image preview and drag-and-drop ordering in edit mode.

## Search
Use filter chips/cards and clear result counts. AI score should be visually distinct but not misleading.

## Accessibility
Use semantic labels, keyboard-friendly controls, readable contrast, focus states, and alt text for meaningful images.

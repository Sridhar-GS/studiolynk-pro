# Rating Specification

## Eligibility
Only after work is `COMPLETED`.

## Directions
Studio -> Freelancer.
Freelancer -> Studio.

## Rating
- 1 to 5 stars
- Optional written review

## Rules
- One rating per direction per completed work.
- Public on the relevant profile.
- Ratings are display-only for ML purposes.
- Ratings do not affect freelancer match score.

## UI
Use star controls and a clear review field.
Show aggregate rating and count on profiles where enough ratings exist.

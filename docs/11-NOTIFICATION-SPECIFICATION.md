# Notification Specification

## In-app only

Notification events:
- Work request received
- Request accepted
- Request rejected
- Studio confirmation
- New message
- Work started
- Work completed
- Work cancelled
- Rating reminder

## Data
- id
- recipient
- type
- title
- message
- related entity id
- created time
- read time/read boolean

## UI
- Bell icon
- Unread count
- Notification list
- Mark one read
- Mark all read
- Link to relevant page
